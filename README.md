# Alibi Platform

⚠️ **Work in Progress — Not Ready for Production**

This repository holds the core development of the Alibi platform. The API layer and several major components are currently under active development and are not stable.

## What's inside?
- **Core Modules**: `core/utils`, `core/sql` — these contain the foundational logic.
- **Code Generation**: `cmd/sqlgen` utility for SQL interface generation.
- **Unstable API**: The `core/api` package is in active development; do not use it for production yet.

## Status & Direction
Currently, the focus of active development has shifted to **Dart/Flutter** for the frontend/GUI layer. Go backend modules are being refined in the background.

For a clean, working showcase of the current mature parts (`utils` and `sql`), please see:
👉 **[alibi-showcase](https://github.com/your-login/alibi-showcase)**

## Contributing
Due to the unstable state of the API layer, we are not accepting external contributions at this time.
